Portfolio performance measures: definitions and implementation

Return to Chapter 3. Undefined ratios remain unavailable. Live fixed-composition, scenario-terminal and observed OOS measures have different samples; their scope must accompany comparisons.

netSD

Candidate dominance-network centrality: (OUT−IN)/D, with D recomputed on the graph augmented by this candidate. See the main methodology for empirical dominance orders and zero-degree convention.

mean_daily

Arithmetic mean of the observed daily simple returns.

mean_annual

252 times the arithmetic daily mean; an annualisation convention, not a forecast.

cumulative_return

Product of (1 + each daily simple return), minus one.

CAGR

Geometric annualised growth based on 252 sessions per year.

std_daily

Sample standard deviation of daily simple returns.

volatility_annual

Daily sample standard deviation multiplied by the square root of 252.

sharpe_annual

Square root of 252 times the daily mean divided by daily sample STD; zero risk-free rate.

sortino_annual

Square root of 252 times the daily mean divided by full-sample downside deviation about zero.

rachev_5

Mean best 5% tail return divided by minus mean worst 5% tail return, using fractional tail mass. Undefined when the loss-tail denominator is absent.

cvar95

Minus the fractional-probability mean of the worst 5% daily returns; a loss-form quantity.

var95

Historical 95% daily loss quantile, under the Current overview quantile convention.

maximum_drawdown

Largest proportional decline from a preceding running wealth maximum; positive loss convention.

current_drawdown

Final wealth decline relative to the preceding running maximum.

calmar

Annualised geometric return divided by maximum drawdown, where defined.

omega

Sum of positive return excesses above zero divided by sum of shortfalls below zero.

positive_days

Fraction of daily returns strictly above zero.

best_day

Largest observed daily simple return.

worst_day

Smallest observed daily simple return.

skewness

Asymmetry of the empirical daily return distribution, using the Current overview sample convention.

excess_kurtosis

Sample tail-weight diagnostic relative to Gaussian kurtosis; not an estimate of future crash probability.

All72 metrics use the native R PerformanceAnalytics expressions below, independently guarded so one undefined ratio cannot remove the other measures. Risk-free rate and minimum acceptable return are0, annual scale252, historical tail probability0.95, simple-return compounding, and the dated EUR S&P500 price benchmark. No significance or forecastability follows from a high fitted ratio. [pa] [sharpe]

\[\bar r=n^{-1}\sum_t r_t,\quad G=\prod_t(1+r_t),\quad r_{ann}=G^{252/n}-1,\quad \sigma_{ann}=\sqrt{252}\,s_r\]

Arithmetic/geometric return, cumulative return and sample-volatility annualisation; short-sample annualisation is a convention, not a forecast.

\[D_t=1-V_t/\max_{u\le t}V_u,\quad MDD=\max_tD_t,\quad UI=\sqrt{n^{-1}\sum_tD_t^2},\quad Pain=n^{-1}\sum_tD_t\]

Drawdown depth and episode duration/recovery use the native package conventions; maximum drawdown is displayed as a nonnegative loss.

\[SR_{ann}=\sqrt{252}\,\bar r/s_r,\quad DD=\sqrt{n^{-1}\sum_t\min(r_t,0)^2},\quad Sortino=\bar r/DD,\quad \Omega=\sum_t(r_t)_+/\sum_t(-r_t)_+\]

Sharpe, full-sample downside deviation, Sortino and Omega with zero target.

\[\alpha=\bar r_p-\beta\bar r_b,\quad TE_{ann}=\sqrt{252}\,s_{r_p-r_b},\quad LPM_k=n^{-1}\sum_t(0-r_t)_+^k\]

CAPM benchmark alpha/beta, tracking error and lower partial moments. Benchmark-dependent definitions use matched dates, with no substitution of a US-dollar index for EUR performance.
