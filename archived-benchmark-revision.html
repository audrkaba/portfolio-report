Archived sample — recomputed benchmark comparisons

Separate revision with Berkshire Hathaway B and S&P 500 in EUR. Archived observations: 1 October 2025–29 October 2026. Original results are preserved below.

1. Introduction and scope

This revision reconstructs the archived dated return sample and checks all 109 original return distributions before adding the comparison assets. The historical composition of “Archived Current” is retained; it is not today's account. No allocation is fitted, no trade is proposed and no historical model is relabelled as compliant with today's execution or concentration rules.

Berkshire Hathaway B is an individual company share. Both comparison assets use dated EUR price returns. Values illustrate EUR15,000 invested at the beginning of each displayed subperiod, without fees, new cash flows or separately paid dividends.

2. Methodology

Comparable returns and performance

The archived portfolio and asset returns are retained. The two US comparison series are converted using dated ECB USD-per-EUR rates and aligned to the archived trading calendar before returns are calculated. There is no backward fill and no extension beyond the last actual quote. Tables include mean return, volatility, Sharpe, Sortino, Rachev, CVaR, drawdown, final wealth and the remaining descriptive ratios used in the main report. Risk-free and target returns are zero; annualisation uses252 observations.

\(W_t=15000\prod_{u=1}^{t}(1+r_u),\quad DD_t=W_t/\max(15000,W_1,\ldots,W_t)-1.\)

Dominance and netSD

Exact empirical FSD, SSD and TSD comparisons use the same272 returns in the full sample. Each candidate is evaluated once against the unchanged86 archived reference assets. A reference asset already in that set is not duplicated. The denominator is recomputed for the augmented graph, rather than inherited from the earlier fixed-denominator calculation. The display matrix also includes the archived portfolios and benchmarks; the scalar netSD reference set is the separately disclosed86-asset set.

\(\operatorname{netSD}(P)=\frac{OUT(P)-IN(P)}{D(P)},\quad D(P)=\max_{j\in R\cup\{P\}}[OUT(j)+IN(j)].\)

\(H_1(x)=n^{-1}\sum_t\mathbf1(r_t\leq x),\quad H_2(x)=n^{-1}\sum_t(x-r_t)_+,\quad H_3(x)=(2n)^{-1}\sum_t(x-r_t)_+^2.\)

Five attained frontiers

The five panels use sample STD, mean absolute deviation, maximum daily loss, fractional-mass CVaR95 and1−netSD. Each line connects the nondominated archived-portfolio points in that panel. These are attained envelopes of the retained finite comparison set, not refitted optimisation frontiers or global-optimality certificates. Connecting segments are visual guides. Individual assets and the benchmarks remain comparison points and are excluded from the portfolio envelope. Original optimisation frontiers remain available in the preserved version.

Relative performance and statistical checks

\(a_t=r_{P,t}-r_{B,t},\quad IR=\sqrt{252}\,\bar a/s_a,\quad\beta=\operatorname{Cov}(r_P,r_B)/\operatorname{Var}(r_B),\quad\alpha_{ann}=252(\bar r_P-\beta\bar r_B).\)

Relative final wealth is \(\prod(1+r_P)/\prod(1+r_B)\). Paired circular moving-block bootstrap comparisons use2000 replicates and5,10,20-session blocks. Two-sided tests use centered bootstrap differences; confidence intervals describe the arithmetic annualised mean active return. Benjamini–Hochberg adjustment is applied within each period/block-length family. These are exploratory comparisons of previously selected portfolios.

The early70% and later30% are retrospective subperiods of the same frozen allocations. They are not newly refitted rolling IS/OOS tests and do not replace the separate ongoing chronological research.
