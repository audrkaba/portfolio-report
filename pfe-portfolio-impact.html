Method and limitations

Historical initial-allocation sensitivity, not reoptimisation or whole-tree terminal netSD. Each case retains every non-PFE recorded target quantity and values it at the latest verified EUR quotes. Replace the PFE holding by the confirmed quantity versus zero; sale proceeds stay as cash. Historical invested-holdings returns exclude cash, so remaining invested weights renormalise. Identical 71 reference asset distributions (PFE included as reference in both cases), plus exactly one portfolio candidate; D is recomputed on each augmented network, including changed incident degrees. The 126 diagnostic observations are excluded. FULL uses the full training sample; R1-R4 exact-date retrospective labels. Wealth feasibility is reported separately: these counterfactuals are not executable or freshly feasible model trade plans.

The main report's 20 model/policy allocation records contain no PFE row. These comparisons do not claim that those models have been reoptimised or corrected.
