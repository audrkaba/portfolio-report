Scope, frozen data and interpretation

This is a six-origin outer-grid pilot using the frozen predecessor inventory and market dataset ending 17 November 2026. It compares finite-policy archive selection (NETSD-OOS) with direct stochastic policy search (NETSD-OOS-STOCH), under standard and A purchase constraints, separately for sale and no-sale permissions. Each uses normalised weighted sums and epsilon constraints at 100 grid settings. Archive policies may themselves contain stochastic recourse.

Only IS scenarios determine a fitted portfolio. Positive IS expected account returns are preferred where found. Fixed normalisation anchors come from the IS calibration pool, with no clipping and no claim of global extrema. Direct stochastic search uses three structured starts and two native search rounds; it is heuristic, not a global optimality certificate. Scenario terminal netSD and daily realised netSD are different quantities.

OOS is the following calendar month. Held-out data run from the end of that OOS window to the frozen dataset endpoint, with the original decision rule replayed. These tails differ in length and overlap across origins. OOS/held-out outcomes are diagnostics, never selection inputs. This pilot does not perform inner preference selection and does not complete the planned 222-origin nested study. A plotted OOS winner must not be treated as an implementable ex-ante recommendation.
